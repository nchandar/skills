# Dev Handoff

## Overview

Use this skill to package the current state so another session or agent can continue quickly without replaying the whole conversation.

## When To Use

Use this skill when:

- work will continue in another session
- another agent needs the current context
- the user wants a durable status summary

## Workflow

1. Summarize the goal, current status, important decisions, and remaining work.
2. Reference durable artifacts instead of copying them.
3. Record the next best step and any blockers.

## Outputs And Handoffs

Typical handoff contents:

- goal
- current state
- important decisions
- relevant file paths or artifacts
- next steps
- blockers or risks

## Common Mistakes

- Repeating entire documents instead of referencing them.
- Leaving out the next action.
- Hiding blockers or open questions.
